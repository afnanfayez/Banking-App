# 💳 Banking App

A **modern financial dashboard** to manage multiple bank accounts, track transactions in real-time, and transfer funds securely.

---

## 📋 Features

- 🔒 **Secure Authentication**
- 🏦 **Connect Multiple Banks** using Plaid
- 📊 **Dashboard Overview**: Total balance, recent transactions, spending categories
- 📑 **Transaction History** with filtering & pagination
- ⚡ **Real-time Updates** across all pages
- 💸 **Funds Transfer** via Dwolla
- 📱 **Responsive Design** for desktop, tablet, and mobile

---

## ⚙️ Tech Stack

- **Next.js & TypeScript** – Frontend & SSR
- **Appwrite** – Backend & Auth
- **Plaid** – Bank integration
- **Dwolla** – Payments & Transfers
- **React Hook Form & Zod** – Forms & Validation
- **TailwindCSS** – Styling
- **Chart.js** – Data visualization
